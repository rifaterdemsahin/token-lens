Build time: extractionDerleme zamanı: çıkarma

scripts/extract_embeddings.py runs inside the Docker build for every model in app/models.py. It downloads tokenizer.json and model.safetensors, parses the safetensors container directly (so bf16 weights work without PyTorch), keeps only the embedding matrix as float16, and computes a 3-component PCA over the whole vocabulary. The runtime image never touches the network.

scripts/extract_embeddings.py, app/models.py içindeki her model için Docker derlemesi sırasında çalışır. tokenizer.json ve model.safetensors dosyalarını indirir, safetensors kapsayıcısını doğrudan okur (bf16 ağırlıklar PyTorch olmadan çalışır), yalnızca embedding matrisini float16 olarak saklar ve tüm sözlük için 3 bileşenli PCA hesaplar. Çalışma zamanı imajı ağa hiç bağlanmaz.

Runtime: API and LensÇalışma zamanı: API ve Lens

app/embeddings.py loads a model lazily (lru_cache), memory-maps embeddings.f16.npy so RAM stays low, and implements tokenization, cosine neighbours (chunked matrix–vector product), analogies (a − b + c, inputs excluded), PCA lookup and concept axes. Every endpoint takes ?model=; the default is GPT-2.

app/embeddings.py modeli ihtiyaç anında yükler (lru_cache), RAM'i düşük tutmak için embeddings.f16.npy dosyasını bellek eşlemesiyle açar; tokenizasyon, kosinüs komşuları, analojiler (a − b + c), PCA ve kavram eksenlerini uygular. Her uç nokta ?model= alır; varsayılan GPT-2'dir.

Concept axesKavram eksenleri

No embedding dimension is labelled. Each axis (Royalty, Femininity, Fruit, Power) is a unit vector built from the mean of word-pair differences, e.g. Femininity = mean(queen−king, woman−man, she−he, girl−boy). A token's score is the cosine between its vector and the axis, so values are comparable across tokens.

Hiçbir embedding boyutunun etiketi yoktur. Her eksen (Krallık, Dişilik, Meyve, Güç) kelime çifti farklarının ortalamasından oluşan birim vektördür; örn. Dişilik = ort(queen−king, woman−man, she−he, girl−boy). Skor, token vektörü ile eksen arasındaki kosinüstür.

FrontendArayüz

Static HTML + vanilla JS + Plotly (pinned CDN version); no build step. Pages: Token Lens, Models, this page. Language (EN/TR) and model choice are remembered in the browser. Sections are collapsible <details> blocks.

Statik HTML + saf JS + Plotly (sabitlenmiş CDN sürümü); derleme adımı yok. Sayfalar: Token Lens, Modeller, bu sayfa. Dil (EN/TR) ve model seçimi tarayıcıda hatırlanır. Bölümler açılıp kapanan <details> bloklarıdır.

Deployment and secretsDağıtım ve gizli bilgiler

One container, python:3.12-slim, multi-stage. Fly.io shared-cpu-1x, 1 GB, region lhr, scale-to-zero. The Fly deploy token is kept in Azure Key Vault and exported only as an environment variable at deploy time. Trade-off: all three models are baked into the image, so it is larger than a GPT-2-only build; matrices are memory-mapped so RAM stays within 1 GB.

Tek konteyner, python:3.12-slim, çok aşamalı. Fly.io shared-cpu-1x, 1 GB, lhr bölgesi, sıfıra ölçekleme. Fly dağıtım token'ı Azure Key Vault'ta tutulur ve yalnızca dağıtım sırasında ortam değişkeni olarak verilir. Ödünleşim: üç model de imaja gömülüdür, bu yüzden yalnızca GPT-2 içeren sürümden büyüktür; matrisler bellek eşlemeli olduğundan RAM 1 GB içinde kalır.
