Models and token IDsModeller ve token ID'leri

A token ID belongs to one tokenizerBir token ID'si tek bir tokenizer'a aittir

A token ID is just a row number in one model's vocabulary. Each model family trains its own tokenizer, so the same text gets different IDs, and the same ID is a different piece of text. There is no universal ID for "king".

Token ID'si yalnızca tek bir modelin sözlüğündeki satır numarasıdır. Her model ailesi kendi tokenizer'ını eğitir; bu yüzden aynı metin farklı ID alır ve aynı ID farklı bir metin parçasıdır. "king" için evrensel bir ID yoktur.

Common mix-up: you may see "king = 9246" quoted as a GPT-2 fact. We checked the real GPT-2 tokenizer: king = 3364, king (with a leading space) = 5822, and 9246 is cat. Always verify an ID against the actual tokenizer. Sık karışıklık: "king = 9246" bazen GPT-2 bilgisi olarak aktarılır. Gerçek GPT-2 tokenizer'ında kontrol ettik: king = 3364, king (başında boşlukla) = 5822 ve 9246 aslında cat. ID'leri her zaman gerçek tokenizer'la doğrulayın.
Same words, different IDs (live from the server)Aynı kelimeler, farklı ID'ler (sunucudan canlı)

Several IDs in one cell = the word is split into several tokens by that model.

Bir hücrede birden fazla ID = kelime o modelde birkaç token'a bölünüyor.

Why the leading space mattersBaştaki boşluk neden önemli

GPT-2 and Qwen use byte-level BPE: a leading space is part of the token, so king and king have different IDs and different vectors. Gemma uses SentencePiece, which writes the space as ▁. Turkish words are often split into several pieces by English-centred vocabularies (GPT-2), and more cleanly by the multilingual ones (Qwen, Gemma).

GPT-2 ve Qwen bayt düzeyinde BPE kullanır: baştaki boşluk token'ın parçasıdır, bu yüzden king ve king farklı ID ve farklı vektörlere sahiptir. Gemma, boşluğu ▁ olarak yazan SentencePiece kullanır. Türkçe kelimeler İngilizce ağırlıklı sözlüklerde (GPT-2) çok parçaya bölünür; çok dilli olanlarda (Qwen, Gemma) daha düzgün bölünür.
