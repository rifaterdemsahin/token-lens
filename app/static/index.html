About the numbersSayılar hakkında

Text → tokenizer vocabulary → integer token ID → row index into the model's embedding matrix → that row is the vector. These are learned weights, not database rows. IDs are arbitrary and specific to each model's tokenizer (see Models). The axis scores are derived: each axis is a direction built from word pairs (shown above); the score is the cosine between a token's vector and that direction.

Metin → tokenizer sözlüğü → tamsayı token ID → modelin embedding matrisindeki satır indeksi → o satır vektördür. Bunlar öğrenilmiş ağırlıklardır, veritabanı satırı değil. ID'ler rastgeledir ve her modelin tokenizer'ına özeldir (bkz. Modeller). Eksen skorları türetilmiştir: her eksen kelime çiftlerinden oluşan bir yöndür (yukarıda gösterilir); skor, token vektörü ile bu yön arasındaki kosinüstür.

Not: Türkçe için çok dilli modelleri (Qwen, Gemma) seçin; eksenler İngilizce kelimelerle tanımlıdır.
