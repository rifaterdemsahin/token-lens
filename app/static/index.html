About the numbers

Text → tokenizer vocabulary (byte-pair encoding) → an integer token ID → that ID is a row index into GPT-2's embedding matrix wte.weight (50,257 × 768) → the 768 numbers in that row are the token's vector.

These are learned weights, not database rows someone typed in. IDs are arbitrary (“king” and “queen” are not adjacent). Individual dimensions have no human-readable label.

The Royalty / Femininity / Fruit / Power numbers are derived: each axis is a direction built from word pairs (e.g. Femininity = mean of queen−king, woman−man, …), normalised; the score is the cosine between a token's vector and that direction. The pairs are shown above.
